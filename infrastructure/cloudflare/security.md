# Cloudflare security baseline

- Enable HTTPS and Always Use HTTPS.
- Keep managed WAF rules enabled.
- Use DDoS protection.
- Use Turnstile where human verification is needed.
- Protect admin, dashboard and development services with Zero Trust Access.
- Use Tunnel for private infrastructure.
- Use least-privilege API tokens.
- Never commit credentials or tunnel JSON files.
- Rotate credentials immediately if exposed.
- Keep public and private hostnames separated.
